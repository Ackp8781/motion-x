# Motion X

A video editor for Windows: layer timeline, keyframes and graphs, 92 GPU effects, masks and groups, frame-by-frame drawing, AI Enhance and Stabilize.

**Website:** https://ackp8781.github.io/motion-x/
**Download:** [MotionX-Windows.zip](https://github.com/Ackp8781/motion-x/releases/latest/download/MotionX-Windows.zip) (Windows 10/11, 64-bit)

Unzip it anywhere and run `Motion X.exe`.
